Group all `src/main/` modules into three tiers:

- `acioemu/`, `bio2emu/` — ACIO/BIO2 emulation

- `d3d9hook/` — D3D9 hooking (has test: `d3d9hook-test`)
- `iidxhook8/` — IIDX8-specific hook (has test: `iidxhook8-test`)

*Tier 3 — Hooks/hardware-dependent (manual testing only):*
- Game-specific hook DLLs: `iidxhook1-9/`, `ddrhook1-2/`, `jbhook1-3/`, `popnhook1/`, `sdvxhook/`, `bsthook/`

  <name>Task 2: Create project-level CLAUDE.md</name>
  <files>CLAUDE.md</files>
  <action>
Create `CLAUDE.md` at the repository root — strict agent guardrails for this project. Per CONTEXT.md, this must be self-contained (no dependency on personal ~/.claude/rules/) and work for any contributor.

**Structure:**

1. **Project overview** (2-3 lines): Bemanitools 5 — Windows DLL injection toolkit for Konami arcade rhythm games. Cross-compiled from Linux via MinGW.

2. **Scope constraints:**
   - BT5 only: do NOT touch BT6 refactoring branches or create BT6 code
   - No new game series support
   - No new dependencies without explicit approval
   - Windows-only target: all code targets Win32 via MinGW cross-compilation

3. **Verification workflow:**
   - Run `scripts/aide-verify.sh` before every commit
   - All three stages (BUILD, FORMAT, TEST) must PASS
   - If FORMAT FAIL: commit the formatted files, then re-run
   - Do NOT skip verification

4. **Coding conventions:**
   - C99 standard, `-Wall` clean
   - `clang-format` with project `.clang-format` config (80 col, 4 spaces, Linux braces)
   - Run `make code-format` before committing
   - Snake_case for functions (prefixed with module name), SCREAMING_SNAKE for constants
   - Test framework: custom `check.h` macros (`TEST_MODULE_BEGIN/END`, `check_int_eq`, etc.) — do NOT introduce external test frameworks
   - New code needs a `Module.mk` in its directory — follow existing examples

5. **Do-not-touch list:**
   - `GNUmakefile` — root build orchestration, complex and fragile
   - Root `Module.mk` — module inclusion list
   - `.clang-format` — established formatting rules
   - `imports/` — third-party import definitions
   - Do NOT modify these without explicit approval

6. **Orientation:** Point to `doc/agent-reference.md` for codebase map, module tiers, and test coverage.

7. **Build quick-reference:**
   - `make build` — compile all targets
   - `make code-format` — apply clang-format
   - `make run-tests` — run tests under Wine
   - `scripts/aide-verify.sh` — full verification loop

Keep it direct and terse. No filler, no explanations of why rules exist unless the "why" prevents a common mistake. Target: <80 lines.
