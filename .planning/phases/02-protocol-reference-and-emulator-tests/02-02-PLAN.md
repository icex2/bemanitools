Create test stub libraries for iidxio, eamio, and time dependencies that emulator tests need to link against.

Purpose: The emulator modules (bio2emu-iidx, acioemu/icca, ezusb-iidx-emu) call iidxio/eamio/time functions directly. Tests cannot link against the real DLL-exported implementations. These stubs provide safe defaults with configurable state, enabling deterministic unit tests without production code changes.

Output: Three stub static libraries at `src/test/stubs/`, integrated into root Module.mk.

**time-stub:**
- `time-stub.c`: Implement ALL functions from `util/time.h`. Include `util/time.h` for signature verification.
  - Static module-level variable: `stub_counter` (uint64_t), `stub_elapsed_ns` (uint64_t), `stub_elapsed_us` (uint64_t), `stub_elapsed_ms` (uint32_t)
  - `time_get_counter`: return `stub_counter`
  - `time_get_elapsed_ns`: return `stub_elapsed_ns` (ignores counter_delta param — test controls return value)
  - `time_get_elapsed_us`: return `stub_elapsed_us`
  - `time_get_elapsed_ms`: return `stub_elapsed_ms`
  - Default values: counter=0, elapsed_us=1000000 (1 second — forces all queued responses to be immediately available in drain), elapsed_ns=1000000000, elapsed_ms=1000
- `time-stub.h`: Declare setter functions:
  - `void time_stub_reset(void)` — reset to defaults (1 second elapsed)
  - `void time_stub_set_counter(uint64_t value)`
  - `void time_stub_set_elapsed(uint64_t ns, uint64_t us, uint32_t ms)` — set all three at once for consistency
- `Module.mk`:
  ```makefile
  libs            += time-stub
  srcdir_time-stub := src/test/stubs/time
  src_time-stub    := time-stub.c
  ```

IMPORTANT: The time-stub REPLACES util's time functions at link time. Test executables that need deterministic time must list `time-stub` in their `libs_` INSTEAD OF (not alongside) the real time symbols from `util`. Since `util` is a single lib containing many symbols, test executables that need the time stub should still link `util` but add `time-stub` first in the `libs_` list so the linker resolves time symbols from the stub first. If this causes duplicate symbol errors, the executor should investigate the linker resolution order and adjust accordingly.
